# Hero atmosphere

`acoustic-studio.webp` (1536 × 1024) and `acoustic-studio-mobile.webp`
(900 × 600) are optimized versions of an AI-generated editorial atmosphere
created for Fretline in this development session.

They depict a generic acoustic guitar, not a verified product or model.
Do not reuse them as catalog or detail photographs. The homepage includes
an explicit AI illustration note and model-independent alt text.

The original generated PNG is retained outside the source checkout in
`/workspace/generated_images/` for this session.
