Description
It All Starts Here
Derived from FG820 which has the solid spruce top and mahogany back/sides, FGX820C has a cutaway body and the electric system. Yamaha’s proprietary under-saddle piezo pickup and System66 analog preamp ensure the solid plugged-in performance.

ข้อมูลสินค้า
Yamaha FGX820C//02 กีต้าร์โปร่งไฟฟ้าดีไซด์สวยงามจากยามาฮ่า ซึ่งรุ่นนี้เป็นทรงคอเว้าแบบเวสเทิร์นที่มีขนาดบอดี้ค่อนข้างใหญ่ ข้อดีของบอดี้แบบนี้คือเสียงที่ออกมาจะฟังค่อนข้างหนาหรือ”เต็ม”เสียง รุ่นนี้ยังมีไม้ปะหน้าเป็นไม้สปรู๊ซหรือไม้ตระกูลสนช่วยทำให้ซาวด์กีต้าร์ออกมานุ่มละมุน รวมไปถึงการใช้ไม้ด้านข้างและส่วนหลังเป็นไม้มะฮอกกานีที่ขึ้นชื่อเรื่องเสียงหนา ส่งผลให้เจ้า FGX820C นั้นเป็นกีต้าร์ที่สมบูรณ์แบบจะตีคอร์ดก็ได้ฟิงเกอร์สไตล์ก็ดี
รุ่นี้ภาคไฟฟ้าปรีแอมป์จะเป็นของยามาฮ่าเองคือรุ่น SYSTEM66 เป็นแบบอนาล็อคที่ใช้กับยามาฮ่ารุ่นสูงๆ เสียงจึงละมุนกลมกล่อม แผงควบคุมสามารถปรับ AMF หรือย่านความถี่ของเสียงได้ตั้งแต่ 80-10k เพิ่มความคมชัดของเสียงได้ คอทำจากไม้นาโต้หรือตระกูลไม้มะฮอกกานีเสียงหนานุ่มอยู่แล้ว ทำให้เสียงของกีต้าร์ตัวนี้นุ่มลึกเกินบรรยาย ใครชอบซาวด์หนานุ่มๆแบบยามาฮ่าก็ต้องจัดรับรองว่าไม่ผิดหวัง
