Description
Stage-ready with a solid top, cutaway body and high-performance electronics.
The FGX800C is the acoustic-electric version of the FG800. New features include the scalloped X bracing and a reverse L block neck attachment, make it an instrument of high quality. Solid spruce top and mahogany back and sides allows the guitars tone to improve with age.
Equipped with a System 66 under-saddle piezo pickup developed by Yamaha. Its controls include a 3-band EQ, an adjustable mid-range frequency control, and a precision chromatic tuner for optimum sound tailoring. The system is powered by easy to obtain AA-size batteries that provide a stable power supply for improved sound quality.

Yamaha FGX800C กีต้าร์โปร่งไฟฟ้างานดีแบรนด์ดังที่นักดนตรีทุกคนต่างยกนิ้ว รุ่นนี้ทาง Yamaha เลือกใช้ไม้หน้าเป็นท็อปโซลิดสปรู๊ซหรือไม้แท้ทั้งแผ่น ทำให้เมื่อเวลาผ่านไปนานเนื้อไม้จะแห้ง ซาวด์จะหวานละมุนมากขึ้น ส่วนข้างและด้านหลังใช้ไม้นาโต้และไม้โอกูเม่ เป็นไม้พันธุ์เดียวกับมะฮอกกานีแต่นิยมปลูกในเอเชีย จึงได้ซาวด์ที่คล้ายคลึงไม้มะฮอกกานี มีความหนาและอบอุ่น ผสมผสานกันได้อย่างลงตัว ส่วนคอนั้นเลือกใช้ไม้นาโต้เช่นเดียวกัน วัสดุอื่นๆบนกีต้ารืไม่ว่าจะเป็นบริดจ์, ฟิงเกอร์บอร์ด และ ส่วนหัว ใช้ไม้โรสวู้ดอย่างดี ให้ซาวด์ที่หนาละมุนสมราคา ภาคไฟฟ้าใช้ของทาง Yamaha เองเป็นรุ่น Yamaha SYSTEM 66 สามารถปรับ EQ ได้ทั้ง 3 ย่านเสียงและมีจูนเนอร์ตั้งสายในตัว ซาวด์ค่อนข้างใสเป็นธรรมชาติ ตัวเดียวสามารถออกงานได้สบายๆ สเป็คแบบนี้ในราคานี้ถือว่าคุ้มค่าอย่างมาก
Yamaha FGX-800C เหมาะกับใคร?
ถ้าหากถามว่ากีต้าร์โปร่ง Yamaha FGX-800C เหมาะกับใครแอดบอกได้เลยว่าเหมาะกับผู้เล่นทุกกลุ่มจริงๆ ครับ ไม่ว่าจะเป็นผู้เล่นมือใหม่ที่กำลังหากีต้าร์ดีๆ สักตัวเพื่อไปฝึกซ้อมแน่นอนว่าเจ้าตัว Yamaha FGX-800C จะต้องตอบโจรย์ของใครหลายคน ไม่ใช้แค่มือใหม่เท่านั้นยังเหมาะกับคนที่อยากได้กีต้าร์ไปเล่นในเวลาว่างหรือคนที่ต้องใช้กีต้าร์เล่นดนตรีกลางคืนก็เหมาะด้วยเช่นกัน ทั้งนี้ด้วยความคุ้มค่าของเจ้าตัว Yamaha FGX-800C ไม่จับจองไม่ได้แล้ว
บทสรุปของเจ้าตัว Yamaha FGX-800C
Yamaha FGX-800C เป็นกีต้าร์ที่มาพร้อมกับความคุ้มค่าไม่ว่าจะเป็นเรื่องสเปคหรือเรื่องเสียงก็ทำออกมาได้ดีเหมือนกัน สเปคที่จะได้กับกีต้าร์ตัวนี้ก็คือ ไม้หน้าเป็นท็อปโซลิดสปรู๊ซ ไม้ข้างและหลังเป็นไม้มะฮอกนีที่เข้ากันอย่างลงตัวของทั้ง 2 ไม้ กีต้าร์ตัวนี้เหมาะกับใคร เหมาะกับผู้เล่นทุกกลุ่มไม่ว่าจะเป็นผู้เล่นมือใหม่ ผู้เล่นที่ต้องการเอาไปเล่นในเวลาว่างและยังเหมาะกับนักดนตรีที่ต้องการจะนำไปเล่นในงานกลางคืนด้วย แอดแนะนำให้เข้าไปจับจองหรือลองก่อนก็ได้
