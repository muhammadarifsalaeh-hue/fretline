นำ ZIP ชุด Yamaha FSX830C นี้เข้าเว็บไซต์ Fretline โดยตรวจสอบโครงสร้างโปรเจกต์ก่อนแก้ไข:
1. เปิดอ่าน yamaha-fsx830c.json และ README_TH.md แล้วใช้ข้อมูลจากไฟล์เป็นแหล่งข้อมูลหลัก ห้ามเดาสเปกเพิ่มเติม
2. ตรวจสอบสินค้า Yamaha FSX830C และชื่อใกล้เคียง FSX830C/02, FGX830C เพื่อหลีกเลี่ยงการสร้างซ้ำหรือแก้ผิดรุ่น หากไม่แน่ใจให้รายงานก่อนแก้ไข
3. คัดลอกภาพ images/yamaha-fsx830c-natural-black.png ไปยังโฟลเดอร์ assets จริงในโปรเจกต์ และแก้ image path ให้ตรงกับโครงสร้างเว็บ
4. เพิ่มหรืออัปเดตสินค้า 1 รายการ ราคา 24,000 บาท พร้อมคำอธิบายและสเปกภาษาไทยครบทุกข้อ
5. เชื่อมกับ Catalog, Search, Compare, Wishlist และ Find My Guitar เฉพาะส่วนที่มีอยู่แล้ว ห้ามรื้อระบบเดิม
6. คงธีมสีดำ-ทอง Responsive บน iPad และข้อมูลกีตาร์รุ่นอื่นทั้งหมด
7. ตรวจสอบข้อสังเกตเรื่องความถูกต้องของสเปกใน notesForReview; อย่าแสดงข้อมูลที่ไม่ยืนยันเป็นข้อเท็จจริงทางการ
8. รัน npm run build หรือคำสั่งทดสอบตามโปรเจกต์ แก้ข้อผิดพลาดที่เกิดจากการเปลี่ยนแปลง และสรุปไฟล์ที่แก้
9. อย่า merge เข้า master โดยไม่ได้รับอนุญาต
