ช่วยเพิ่ม/อัปเดต Yamaha FG820-12 ในเว็บไซต์ Fretline จากไฟล์แนบ ZIP นี้

1. ตรวจสอบโครงสร้าง React/Vite และสคีมาข้อมูลสินค้าเดิมก่อนลงมือ แก้ไขเฉพาะส่วนที่จำเป็น
2. ค้นหารุ่น Yamaha FG820-12 ในฐานข้อมูลก่อน ถ้ามีแล้วให้อัปเดตของเดิมโดยคง ID ที่มีอยู่ ห้ามเพิ่มรุ่นซ้ำ หากยังไม่มีให้เพิ่มโดยไม่ทำลายแผนจำนวน 200 รุ่น / 10 แบรนด์ แบรนด์ละ 20 รุ่น และรายงานหากจำเป็นต้องตัดสินใจแทนรุ่นใด
3. คัดลอกภาพ yamaha-fg820-12-natural.png ไปยัง public/images/guitars/ หรือโฟลเดอร์ asset ตามระบบที่ใช้อยู่ และอ้างอิง path ให้ถูกต้อง ห้ามเปลี่ยนสี พื้นหลัง หรือครอปกีตาร์โดยไม่จำเป็น
4. ใช้ product.json เป็นข้อมูลตั้งต้น แปลง field ให้ตรงกับสคีมาของเว็บ ไม่แทนที่ฐานข้อมูลทั้งก้อน แสดงชื่อ Yamaha FG820-12, ราคา 18,200 บาท, ภาพ, คำบรรยายภาษาไทย, สเปกทั้งหมดในหน้า Catalog/Detail และระบบ Compare/Find My Guitar หากเกี่ยวข้อง
5. รุ่นนี้เป็นกีตาร์โปร่ง 12 สาย อย่าสับสนกับ FG820 6 สาย; ห้ามเพิ่ม SYSTEM66/pickup โดยไม่มีแหล่งยืนยัน
6. รักษาการทำงานของหน้าอื่น Wishlist, Compare, Catalog, Homepage, Brand Directory และข้อมูลกีตาร์ทั้งหมด
7. ตรวจสอบ image loading, responsive iPad Safari, npm run build และชุดทดสอบที่มีอยู่
8. ทำงานบน branch ที่กำลังใช้โดยปลอดภัย ห้าม merge เข้า master เอง รายงานไฟล์ที่แก้ไข ผลทดสอบ และสิ่งที่ต้องยืนยัน

ข้อมูลสเปกตรวจจากเว็บไซต์ Yamaha (ลิงก์ใน product.json) ราคาตามผู้ใช้แจ้ง
