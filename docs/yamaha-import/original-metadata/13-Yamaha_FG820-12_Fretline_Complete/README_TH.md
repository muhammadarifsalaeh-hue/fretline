Yamaha FG820-12 เป็นกีตาร์โปร่ง 12 สายทรง Traditional Western (Dreadnought) รุ่นต่อยอดจาก FG820 โดดเด่นด้วยไม้หน้าโซลิดสปรูซและไม้หลังกับไม้ข้างมะฮอกกานี ให้เสียงอบอุ่น หนักแน่น และมีมิติจากเสียงสายคู่ พร้อมโครงสร้างค้ำยัน Scalloped Bracing ที่ออกแบบเพื่อการตอบสนองของเสียง เหมาะสำหรับผู้เล่นที่ต้องการความกังวานของกีตาร์ 12 สาย มาในสีไม้ธรรมชาติ (Natural) และรูปลักษณ์คลาสสิก
