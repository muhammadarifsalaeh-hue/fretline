# คำสั่งสำหรับ Codex — Yamaha FS800

ช่วยนำ ZIP นี้ไปเพิ่มหรืออัปเดต Yamaha FS800 ในเว็บไซต์ Fretline โดยใช้รูปและข้อมูลจากแพ็กเกจเท่านั้น

1. อ่าน README_TH.md และ yamaha-fs800.json ก่อนลงมือ ตรวจสอบโครงสร้างและ schema ของโปรเจกต์จริงก่อนปรับรูปแบบข้อมูล
2. ตรวจหา Yamaha FS800 จาก id/model/brand; ถ้ามีให้อัปเดต ห้ามสร้างรายการซ้ำ และอย่าสับสนกับ FG800, FS820 หรือ FS830
3. คัดลอกภาพ images/yamaha-fs800-three-colors.jpg ไปยัง asset directory ที่โปรเจกต์ใช้จริง แล้วแก้ image URL ให้ตรง ห้ามอ้างไฟล์ที่ไม่มีอยู่
4. รักษาสัดส่วนรูป 1254x1254 และพื้นหลังดำ ไม่บิดหรือครอปกีตาร์
5. แสดงราคา 12,400 บาท พร้อมระบุเป็นราคาอ้างอิงจากร้านค้า ณ วันที่ 25 ตุลาคม 2026 ไม่ใช่ราคาทางการ
6. ใส่ descriptionTH และ specificationsTH ให้ครบ และเก็บ source links ไว้ใน metadata หากระบบรองรับ
7. ภาพสามสีเป็นภาพประกอบของรุ่นเดียว ไม่สร้าง 3 รายการ และอย่ากำหนดชื่อสีโดยอาศัยภาพอย่างเดียว
8. เชื่อม Catalog, Search, Compare, Wishlist และ Find My Guitar เฉพาะตามระบบที่มีอยู่ ไม่เขียนระบบใหม่โดยไม่จำเป็น
9. รักษาดีไซน์ดำ-ทอง ข้อมูลกีตาร์รุ่นอื่น และเป้าหมาย 200 รุ่นของเว็บ
10. รัน build/tests ที่โปรเจกต์รองรับ ตรวจภาพและหน้ารายละเอียดบนจอ iPad และรายงานไฟล์ที่เปลี่ยนกับผลทดสอบ
11. ห้าม merge เข้า master โดยไม่ได้รับอนุญาต
