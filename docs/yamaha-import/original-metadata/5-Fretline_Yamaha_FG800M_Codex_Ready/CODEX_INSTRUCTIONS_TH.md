# คำสั่งนำ Yamaha FG800M เข้า Fretline

ตรวจสอบ repository และ data schema จริงก่อนแก้ไข ห้ามสมมติว่าโปรเจกต์ใช้ JSON schema นี้โดยตรง ให้แปลงเข้ารูปแบบเดิมของ Fretline

1. ใช้ภาพ `images/yamaha-fg800m-natural-black-background.png` ซึ่งเป็นภาพที่ผู้ใช้แนบมาโดยตรง คัดลอกไปยัง asset directory ที่มีอยู่จริง และแก้ path ให้ถูกต้อง
2. อ่าน `yamaha-fg800m.json` และเพิ่ม/อัปเดตรายการ Yamaha FG800M ราคา 12,400 บาท พร้อมคำอธิบายและสเปกภาษาไทย
3. ตรวจสอบ FG800M ที่มีอยู่แล้วก่อน หากพบให้อัปเดต record เดิมและรักษา ID เดิม ห้ามสร้างรายการซ้ำ ห้ามสับสนกับ FG800, FG800J หรือ FG820
4. ตรวจสอบความขัดแย้งระหว่างรูปภาพกับข้อมูล: ภาพมีปิ๊กการ์ดลายกระดองเต่า แต่สเปกที่ผู้ใช้ส่งระบุสีดำ; คำว่า FG800M อาจสื่อถึง matte finish แต่ข้อมูลผู้ใช้ระบุเคลือบเงา อย่าระบุเป็นข้อเท็จจริงที่ยืนยันแล้วจนกว่าจะตรวจสอบกับแหล่งทางการ หากยืนยันไม่ได้ให้แจ้งผู้ใช้และทำเครื่องหมายรอตรวจสอบ
5. ให้ข้อมูลใน Catalog, Detail, Compare, Wishlist, Search, Find My Guitar ทำงานตามโครงสร้างเดิม ห้ามเปลี่ยน behavior ของระบบอื่น
6. รักษาดีไซน์สีดำ-ทองและการแสดงผล responsive บน iPad และมือถือ
7. รักษาเป้าหมายข้อมูลกีตาร์ 200 รุ่น ถ้ารายการเดิมมีอยู่แล้วให้อัปเดตโดยไม่เพิ่มจำนวน หากไม่มีให้แจ้งผลกระทบต่อจำนวนและไม่ลบรายการอื่นเพื่อให้ครบ 200
8. รัน test/build ตาม scripts ที่มีจริง ตรวจสอบ asset load และรายงานไฟล์ที่เปลี่ยน ผลทดสอบ และจุดที่รอตรวจสอบ
9. ห้าม merge เข้า master โดยไม่ได้รับอนุญาต
