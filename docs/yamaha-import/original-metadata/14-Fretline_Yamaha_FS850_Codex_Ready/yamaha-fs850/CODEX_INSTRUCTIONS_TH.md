# คำสั่ง Codex — Yamaha FS850 สำหรับ Fretline

โปรดตรวจสอบโครงสร้าง repository ก่อนแก้ไข และนำข้อมูลจาก `yamaha-fs850.json` กับภาพ `images/yamaha-fs850-black-background.png` ไปใส่ในเว็บไซต์ Fretline

1. ตรวจสอบรายการ Yamaha FS850 เดิมด้วยทั้ง ID และชื่อรุ่น หากมีอยู่แล้วให้อัปเดตรายการเดิมและคง ID ที่ใช้อยู่ ห้ามสร้างรายการซ้ำ
2. ใช้ภาพที่แนบมาโดยตรง (ไม่สร้างภาพใหม่ ไม่ใช้ภาพ placeholder) คัดลอกไปยังตำแหน่ง asset ที่สอดคล้องกับโปรเจกต์ และแก้ image path ให้ถูกต้องกับโครงสร้างจริง
3. แสดงราคา 19,700 บาท คำอธิบายภาษาไทย และสเปกทุกหัวข้อจาก JSON ใน Catalog และหน้ารายละเอียดตามที่ระบบรองรับ
4. รุ่นนี้คือ Yamaha FS850 ทรง Concert 6 สาย ไม่ใช่ FG850 หรือ FG800M
5. รักษา Catalog, Compare, Wishlist, Search, Find My Guitar และดีไซน์ดำ-ทองเดิม ห้ามเปลี่ยนข้อมูลรุ่นอื่นหรือเพิ่มรายการซ้ำจนกระทบเป้าหมาย 200 รุ่น
6. ข้อมูลจากผู้ใช้ยังไม่ผ่านการยืนยันทางการ: โดยเฉพาะข้อความเกี่ยวกับ bracing, binding, soundhole และ headstock veneer ให้คงคำว่า 'ตามข้อมูลที่ให้' หรือแจ้งให้ตรวจสอบก่อนเผยแพร่ อย่าแต่งเติมสเปก
7. ตรวจสอบบนขนาดจอ iPad และมือถือ และรัน npm run build รวมถึง tests ที่โปรเจกต์มี
8. ห้าม merge เข้า master โดยไม่ได้รับอนุญาต
9. รายงานไฟล์ที่เปลี่ยน ผลการทดสอบ และข้อมูลที่ต้องยืนยัน
