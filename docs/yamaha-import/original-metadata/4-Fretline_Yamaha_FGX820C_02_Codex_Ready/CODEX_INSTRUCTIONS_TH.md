# คำสั่งสำหรับ Codex — Fretline Yamaha FGX820C//02

ตรวจสอบโครงสร้างโปรเจกต์ Fretline ก่อนแก้ไข แล้วนำข้อมูลจาก `yamaha-fgx820c-02.json` และภาพ `images/yamaha-fgx820c-02.png` เข้าระบบสินค้า

1. ตรวจสอบว่ามี Yamaha FGX820C//02 หรือ FGX820C อยู่แล้วหรือไม่ ถ้ามีให้อัปเดต ห้ามสร้างข้อมูลซ้ำ และอย่าสับสนกับ FSX830C/02
2. ปรับฟิลด์ JSON ให้เข้ากับ schema จริงของโปรเจกต์ อย่าบังคับใช้ schema ตัวอย่างหากไม่ตรง
3. คัดลอกภาพไปยัง asset path จริง แล้วปรับ `image` ให้ถูกต้อง โดยคงสัดส่วนภาพ 1254×1254
4. แสดงราคา 20,500 บาท คำบรรยายภาษาไทยและสเปกทั้งหมด โดยภาพสองสีเป็นภาพประกอบของรุ่นเดียว
5. เชื่อม Catalog, Search, Compare, Wishlist และ Find My Guitar เฉพาะส่วนที่โปรเจกต์รองรับอยู่แล้ว
6. ตรวจสอบข้อมูลที่มีหมายเหตุ โดยเฉพาะชนิด pickup กับ System66; อย่าเดาหรือแสดงว่าได้รับการยืนยันแล้ว
7. ห้ามลบหรือเปลี่ยนข้อมูลกีตาร์อื่น รักษาธีมดำทองและเป้าหมายข้อมูล 200 รุ่น
8. รันคำสั่ง build/test ตาม package.json และรายงานผลพร้อมไฟล์ที่เปลี่ยน
9. อย่า merge เข้า master โดยไม่ได้รับอนุญาต
