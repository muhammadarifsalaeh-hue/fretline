# คำสั่งสำหรับ Codex — เพิ่ม Yamaha FG830 ลงใน Fretline

โปรดนำข้อมูลและภาพจาก ZIP นี้ไปเพิ่มในเว็บไซต์ Fretline ที่มีอยู่ โดยรักษาโค้ดและฟีเจอร์เดิมทั้งหมด

## ข้อมูลสินค้า
- แบรนด์: Yamaha
- รุ่น: FG830
- ชื่อ: Yamaha FG830 Acoustic Guitar
- ราคา: 17,500 บาท
- ประเภท: กีตาร์โปร่ง
- รายละเอียดภาษาไทยและสเปกทั้งหมด: อ่านจาก `yamaha-fg830.json`
- ภาพสินค้า: `images/yamaha-fg830-three-colors.jpg` (ภาพรวม 3 สี พื้นหลังดำ)

## วิธีดำเนินการ
1. ตรวจสอบโครงสร้างโปรเจกต์และไฟล์ข้อมูลกีตาร์เดิมก่อน อย่าเดาชื่อไฟล์หรือแก้ทับข้อมูลโดยไม่ตรวจสอบ
2. คัดลอกภาพไปยังตำแหน่ง asset ที่เหมาะสม เช่น `public/images/guitars/yamaha-fg830-three-colors.jpg` แล้วปรับ path ให้ตรงกับระบบจริง
3. ค้นหา Yamaha FG830 ในฐานข้อมูลเดิมก่อน หากมีอยู่แล้ว ให้ปรับปรุงเฉพาะภาพ ราคา คำอธิบาย และสเปก โดย **รักษา ID เดิม** และความสัมพันธ์ของข้อมูล หากไม่มี ให้เพิ่มเป็นรุ่นใหม่โดยไม่สร้างรายการซ้ำ
4. แสดงราคาเป็น `฿17,500` และแสดงคำอธิบายภาษาไทยกับสเปกครบทุกข้อบนหน้ารายละเอียดสินค้า
5. ใช้ภาพที่ให้เป็นภาพสินค้า 1 ภาพที่แสดง 3 สี **ห้ามแยกเป็น 3 รุ่นใหม่** และห้ามสมมติว่ามีภาพแยกแต่ละสี
6. ตรวจสอบภาพบนหน้ารวมสินค้า หน้ารายละเอียด การค้นหา การเปรียบเทียบ Wishlist และ Find My Guitar หากฟีเจอร์เหล่านี้ใช้ข้อมูลเดียวกัน
7. คงดีไซน์ดำ-ทองของ Fretline และไม่เปลี่ยนจำนวนรุ่น 200 รุ่นหรือสัดส่วนแบรนด์ 20 รุ่นโดยไม่จำเป็น ถ้ารายการเดิมเต็ม ให้รายงานก่อนว่าจะปรับอะไร
8. ห้ามลบหรือทำให้ข้อมูลและฟีเจอร์เดิมเสียหาย ห้าม merge เข้า master โดยไม่ได้รับอนุญาต
9. รันการทดสอบที่โปรเจกต์มี เช่น build, catalog/data validation และตรวจสอบว่า image path โหลดได้จริง
10. สรุปไฟล์ที่แก้ไข ผลการทดสอบ และภาพหน้าจอหากทำได้

หมายเหตุ: ภาพเป็นภาพประกอบที่ผู้ใช้จัดเตรียม ไม่ควรอ้างว่าเป็นภาพทางการของผู้ผลิต ราคาและสเปกเป็นข้อมูลจากผู้ใช้
