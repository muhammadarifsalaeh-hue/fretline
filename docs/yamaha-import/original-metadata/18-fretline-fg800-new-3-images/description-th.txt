กีตาร์โปร่ง Yamaha FG800 Acoustic Guitar

Yamaha FG800 เป็นกีตาร์โปร่งสำหรับผู้เริ่มต้นในราคาที่เข้าถึงได้ โดยใช้ไม้หน้าโซลิดซิตกาสปรูซ (Solid Sitka Spruce) ซึ่งเป็นไม้ยอดนิยมในการผลิตกีตาร์ ให้โทนเสียงนุ่มนวล มีการตอบสนองต่อการดีดที่ค่อนข้างช้า และมีน้ำหนักเบา จึงเหมาะกับผู้เริ่มต้นที่กำลังฝึกฝนและค้นหาแนวทางการเล่นของตนเอง

ไม้ด้านหลังและด้านข้างทำจากไม้นาโต (Nato) ช่วยให้ตัวกีตาร์มีน้ำหนักเบาและราคาไม่สูง โดยยังรักษาคุณภาพเสียงไว้

รายละเอียดเพิ่มเติม ได้แก่ ฟิงเกอร์บอร์ดและบริดจ์ไม้โรสวูด (Rosewood), ขอบตัวกีตาร์สีดำและสีขาว, ลูกบิดแบบ Die-cast และปิ๊กการ์ดลายกระดองเต่า

หมายเหตุ: คำบรรยายนี้แปลจากข้อความภาษาอังกฤษที่ผู้ใช้ให้มา ยังไม่ได้ยืนยันข้อมูลสเปกกับผู้ผลิต รูปภาพเป็นภาพประกอบที่สร้างด้วย AI ไม่ใช่ภาพถ่ายสินค้าจริง
