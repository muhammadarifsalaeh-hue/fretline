# คำสั่ง Codex: เพิ่ม Yamaha FS820 ลง Fretline

โปรดเปิดและตรวจสอบโครงสร้าง repository Fretline ก่อนแก้ไขใด ๆ แล้วนำข้อมูลจาก `yamaha-fs820.json` และภาพ `images/yamaha-fs820-four-colors.jpg` ในแพ็กเกจนี้เข้าเว็บไซต์จริง

1. ตรวจสอบ schema/ไฟล์ฐานข้อมูลสินค้าและ conventions ของโปรเจกต์ก่อน แปลงฟิลด์ JSON ให้เข้ากับ schema เดิม อย่าสร้างระบบข้อมูลใหม่โดยไม่จำเป็น
2. ใช้รหัสสินค้า `yamaha-fs820` ตรวจหารุ่นนี้ก่อน หากมีแล้วให้อัปเดต ห้ามสร้างข้อมูลซ้ำ
3. คัดลอกภาพไปยังโฟลเดอร์ public/assets ที่โปรเจกต์ใช้จริง และปรับ image URL ตามโครงสร้างจริง ห้ามใช้ path ใน JSON โดยไม่ตรวจสอบว่าใช้งานได้
4. ภาพเป็นกีตาร์ 4 สีในภาพเดียว ให้เป็นภาพหลักของรุ่น FS820 เพียงรุ่นเดียว ไม่เพิ่ม 4 รายการ
5. แสดงชื่อ ราคา **15,400 บาท** คำอธิบายภาษาไทย และสเปกทั้งหมดในหน้ารายละเอียด
6. เชื่อมกับ Catalog, Search, Compare, Wishlist, Find My Guitar เท่าที่มีอยู่จริง โดยไม่ทำให้ฟีเจอร์เดิมเสีย
7. รักษาดีไซน์สีดำ-ทอง รองรับ iPad/mobile และแผนข้อมูล 200 รุ่น
8. มีความขัดแย้งในข้อความผู้ใช้: คำบรรยายกล่าวว่าไม้หน้า Solid Mahogany แต่รายการสเปกระบุ Solid Spruce ให้แสดง Solid Spruce ตามรายการสเปก และระบุจุดนี้ในรายงาน ห้ามสร้างข้อมูลสเปกเพิ่มเอง
9. รันคำสั่ง build/test ที่เหมาะสม รายงานผลและไฟล์ที่แก้ไข พร้อมตรวจสอบว่ารูปโหลดได้
10. อย่าลบข้อมูลเดิมหรือ merge เข้า master โดยไม่ได้รับอนุญาต
