# คำสั่งสำหรับ Codex — นำเข้า Yamaha FSX800C ใน Fretline

โปรดตรวจสอบโครงสร้างโปรเจกต์ Fretline ที่มีอยู่ก่อนแก้ไข แล้วนำข้อมูลจาก ZIP นี้ไปเพิ่ม/อัปเดต Yamaha FSX800C โดยรักษาระบบเดิมทั้งหมด

1. เปิด `yamaha-fsx800c.json` ซึ่งมีข้อมูลภาษาไทย ราคา 14,200 บาท และสเปกที่แปลเป็นไทยแล้ว อย่าทิ้งฟิลด์หรือสเปกใด ๆ
2. นำภาพจริงจาก `images/yamaha-fsx800c-three-colors.jpg` ไปไว้ในตำแหน่ง asset ที่เหมาะกับโครงสร้าง repo และแก้ path ให้ถูกต้อง ภาพมีสามสีในไฟล์เดียว ห้ามสร้างสามสินค้าแยกกัน
3. ค้นหารุ่น FSX800C เดิมโดยตรวจสอบ id/model แบบไม่สนตัวพิมพ์เล็กใหญ่ หากมีแล้วให้อัปเดต ไม่สร้างรายการซ้ำ และอย่าแก้รุ่น FS800/FGX800C/FSX820C
4. แปลง schema จาก JSON ชุดนี้ให้เข้ากับ schema ปัจจุบันของ Fretline โดยไม่เปลี่ยนโครงสร้างระบบหลัก ใช้ราคาเป็นตัวเลข THB = 14200
5. แสดงชื่อรุ่น คำอธิบายภาษาไทย สี ราคา และสเปกครบ 30 รายการในหน้ารายละเอียดสินค้า พร้อม alt text รูปภาพ
6. ให้สินค้าทำงานกับ Catalog, Search, Compare, Wishlist และ Find My Guitar ตามที่ระบบเดิมรองรับ
7. รักษาธีมสีดำ-ทอง ดีไซน์ responsive บน iPad และข้อมูลกีตาร์รุ่นอื่นทั้งหมด รวมถึงเป้าหมาย 200 รุ่น
8. ตรวจสอบความขัดแย้งที่ระบุใน `reviewNotes` ก่อนเผยแพร่ โดยเฉพาะสีขอบบอดี้; ไม่เดาข้อมูลใหม่
9. รัน lint/test/build ที่มีอยู่ ตรวจสอบ path ภาพและหน้าเว็บ สรุปไฟล์ที่แก้ไขและผลการทดสอบ
10. อย่า merge เข้า master/main โดยไม่ได้รับอนุญาต
