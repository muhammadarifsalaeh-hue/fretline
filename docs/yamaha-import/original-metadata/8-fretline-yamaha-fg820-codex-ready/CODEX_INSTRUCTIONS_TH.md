# คำสั่งสำหรับ Codex — Yamaha FG820 / Fretline

โปรดอ่านไฟล์ `yamaha-fg820.json` และใช้ภาพ `images/yamaha-fg820-five-colors-black.jpg` จาก ZIP นี้เพื่ออัปเดตข้อมูลกีตาร์ Yamaha FG820 ในเว็บ Fretline

## สิ่งที่ต้องทำ
1. ตรวจสอบโครงสร้างโปรเจกต์และฐานข้อมูลกีตาร์ก่อนแก้ไข ค้นหา FG820 เดิมด้วย brand/model และ ID ที่มีอยู่
2. ถ้ามี FG820 แล้วให้อัปเดตข้อมูลเดิมโดยคง ID เดิม ห้ามเพิ่มซ้ำ ถ้าไม่มีจริงจึงค่อยสร้างรายการใหม่ โดยรายงานผลกระทบต่อข้อกำหนด 200 รุ่น / 10 แบรนด์ แบรนด์ละ 20 รุ่นก่อนดำเนินการ
3. ใช้รูปที่แนบจากไฟล์จริง ไม่ใช้ภาพตัวอย่างหรือ URL ภายนอก คัดลอกไปยัง asset path ตาม convention ของโปรเจกต์ แล้วปรับ reference ให้ถูกต้อง
4. ใช้รูปภาพรวม 5 สีเป็นภาพเดียวใน gallery/thumbnail อย่าตัดภาพหรือสร้างสินค้าแยก 5 รุ่นเอง
5. ตั้งชื่อ Yamaha FG820 Acoustic Guitar, ราคา 15,400 บาท, คำอธิบายภาษาไทยและสเปกตาม JSON ให้ครบ แสดงผลอ่านง่ายบนหน้ารายละเอียด
6. คงดีไซน์ดำ-ทองเดิม และรักษา Homepage, Brand Directory, Catalog, Guitar Detail, Compare, Wishlist, Find My Guitar และหน้า Practice
7. ห้ามแก้ข้อมูลรุ่นอื่นโดยไม่จำเป็น ห้ามลบข้อมูลหรือทำให้จำนวนกีตาร์ 200 รุ่นเสียหาย
8. ตรวจสอบภาพโหลดได้จริงบน iPad/mobile, รัน build และ tests ที่เกี่ยวข้อง
9. ห้าม merge เข้า master โดยไม่ได้รับอนุญาต ให้ทำงานบน branch ที่เหมาะสมและรายงาน branch/commit
10. รายงานไฟล์ที่เปลี่ยน จำนวนรุ่นก่อน/หลัง และผลทดสอบ พร้อมระบุสเปกที่ยังควรตรวจสอบกับผู้ผลิต ไม่เติมข้อมูลที่ไม่มีแหล่งอ้างอิง
