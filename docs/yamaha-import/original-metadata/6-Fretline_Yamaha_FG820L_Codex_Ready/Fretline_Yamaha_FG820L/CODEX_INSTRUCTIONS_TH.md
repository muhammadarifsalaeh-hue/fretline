# คำสั่งสำหรับ Codex — Fretline Yamaha FG820L

อ่านไฟล์นี้และ `yamaha-fg820l.json` ก่อนเริ่มทำงาน

## เป้าหมาย
นำ Yamaha FG820L กีตาร์โปร่งสำหรับคนถนัดซ้าย ราคา 18,200 บาท เข้าเว็บไซต์ Fretline โดยใช้ภาพ PNG พื้นหลังดำที่ผู้ใช้ส่งมาภายใน ZIP และคำอธิบาย/สเปกภาษาไทยจาก JSON

## ขั้นตอน
1. ตรวจสอบโครงสร้างโปรเจกต์และรูปแบบข้อมูลจริงก่อนแก้ไข (ไม่สมมติชื่อไฟล์หรือ schema)
2. ค้นหา Yamaha FG820L ในแค็ตตาล็อก หากมีอยู่ให้อัปเดตข้อมูลและคง ID เดิม หากยังไม่มีจึงเพิ่มรุ่นนี้โดยไม่สร้างรายการซ้ำ
3. คัดลอก `images/yamaha-fg820l-natural-black-background.png` ไปยังโฟลเดอร์ assets ที่ใช้งานจริง ปรับ path ในข้อมูลให้ถูกต้อง และทดสอบโหลดภาพ
4. นำข้อมูลใน `yamaha-fg820l.json` มาแมปกับ schema ของเว็บอย่างระมัดระวัง: ราคา 18200 THB, brand Yamaha, model FG820L, handedness=left, คำอธิบายภาษาไทย, และสเปกทั้งหมด
5. ยืนยันว่าแสดงข้อความ “สำหรับผู้ถนัดซ้าย” อย่างชัดเจนในหน้า Catalog และ Product Detail และไม่สับสนกับ FG820 (มือขวา) หรือ FG820-12 (12 สาย)
6. ตรวจสอบทิศทางกีตาร์ในภาพก่อนแสดงว่าเป็นรุ่นมือซ้าย หากไม่สามารถยืนยันจากภาพได้ ให้แจ้งผู้ใช้ ไม่ต้องกลับด้านภาพเองโดยไม่มีคำสั่ง
7. เชื่อมกับการค้นหา Compare, Wishlist, Find My Guitar เฉพาะตามระบบที่มีอยู่แล้ว ห้ามทำฟีเจอร์เดิมเสีย
8. รักษาดีไซน์สีดำ-ทอง รองรับมือถือ/iPad และจำนวนรายการเป้าหมาย 200 รุ่น ไม่เพิ่มรายการซ้ำหรือแทนที่กีตาร์อื่นโดยพลการ
9. ทดสอบคำสั่ง build/lint/test ตามที่โปรเจกต์รองรับ แล้วรายงานไฟล์ที่แก้และผลทดสอบ
10. ห้าม merge เข้า master หรือเปลี่ยน branch โดยไม่ได้รับอนุญาต

## ข้อควรระวัง
- สเปกและราคาเป็นข้อมูลที่ผู้ใช้ส่งมา ไม่ใช่ข้อมูลที่ตรวจสอบจาก Yamaha แล้ว
- อย่าอ้างว่ารูปเป็นภาพสินค้าทางการ: ภาพนี้เป็นภาพสำหรับประกอบหน้าเว็บ
- ไม่ต้องสร้างกีตาร์ 12 สาย รุ่นนี้คือ FG820L สำหรับมือซ้าย 6 สาย
