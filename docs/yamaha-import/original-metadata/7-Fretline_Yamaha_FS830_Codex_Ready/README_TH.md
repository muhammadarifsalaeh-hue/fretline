- `images/yamaha-fs830-three-colors.png`: ภาพที่ผู้ใช้ส่งมา ขนาด 1000×1000 พิกเซล พื้นหลังดำ
- `yamaha-fs830.json`: ราคา 16,000 บาท (ตามผู้ใช้), คำอธิบายภาษาไทย, สเปกจาก Yamaha, แหล่งข้อมูล
- `CODEX_INSTRUCTIONS_TH.md`: คำสั่งให้ Codex นำข้อมูลเข้าเว็บโดยรักษาระบบเดิม
