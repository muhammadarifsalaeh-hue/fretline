2. คัดลอก `images/yamaha-fs830-three-colors.png` ไปยัง public assets หรือโฟลเดอร์ภาพสินค้าที่เหมาะสม แล้วปรับ image path ให้ตรงกับโครงสร้างโปรเจกต์จริง ภาพต้องแสดงผลจริงและคงสัดส่วน 1000×1000 ไม่ยืดหรือครอปกีตาร์

5. แสดงข้อมูลใน Catalog, Detail, Search, Compare, Wishlist และ Find My Guitar ตามฟีเจอร์ที่มีอยู่แล้ว ไม่เพิ่มระบบใหม่โดยไม่จำเป็น
