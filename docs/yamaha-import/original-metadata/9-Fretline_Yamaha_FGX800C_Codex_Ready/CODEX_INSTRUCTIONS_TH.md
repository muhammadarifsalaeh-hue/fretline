# คำสั่งสำหรับ Codex — Yamaha FGX800C

นำแพ็กเกจนี้เข้าเว็บไซต์ Fretline โดยเริ่มจากตรวจสอบโครงสร้างโปรเจกต์และ schema ข้อมูลกีตาร์ที่ใช้อยู่จริง ห้ามสมมติ path หรือชื่อ field ว่าตรงกับ JSON นี้เสมอไป

1. อ่าน `yamaha-fgx800c.json` และภาพ `images/yamaha-fgx800c-three-colors.jpg`
2. ค้นหาข้อมูล Yamaha FGX800C ในฐานข้อมูลปัจจุบัน หากมีอยู่แล้วให้อัปเดต ห้ามสร้างซ้ำ (รวมการ normalize รหัสรุ่น)
3. นำภาพ JPG ไปไว้ใน asset directory ที่ใช้งานจริง แล้วแก้ image path ให้ถูกต้อง รักษาอัตราส่วน 1:1 ห้าม crop กีตาร์ และตรวจสอบว่าเปิดภาพได้
4. ราคา 15,500 บาท เป็นราคาที่ผู้ใช้กำหนด แสดงคำอธิบายและสเปกภาษาไทยจาก JSON ครบถ้วน
5. ภาพกีตาร์สามสีเป็นภาพประกอบของรุ่นเดียว ไม่ใช่สาม SKU หรือสามรุ่น
6. ตรวจสอบสเปกที่มี reviewNotesTH กับแหล่งทางการก่อนเผยแพร่ โดยเฉพาะ scale 25.6 นิ้ว อย่าแก้ค่าจากผู้ใช้โดยไม่รายงานความต่าง
7. เชื่อมเข้ากับ Catalog, Search, Compare, Wishlist และ Find My Guitar เท่าที่มีระบบอยู่แล้ว อย่าสร้างระบบใหม่โดยไม่จำเป็น
8. รักษาธีมดำ-ทอง การทำงานเดิม และข้อมูลกีตาร์รุ่นอื่น เป้าหมาย 200 รุ่น
9. รัน build/test ที่มีอยู่ ตรวจสอบ responsive บน iPad และรายงานไฟล์ที่แก้ไข ผลการทดสอบ และข้อสงสัยเกี่ยวกับสเปก
10. ห้าม merge เข้า master หรือ deploy โดยไม่ได้รับอนุญาต
