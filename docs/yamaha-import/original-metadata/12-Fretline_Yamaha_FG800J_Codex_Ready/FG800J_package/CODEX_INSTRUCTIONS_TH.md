เพิ่มหรืออัปเดต Yamaha FG800J ในโปรเจกต์ Fretline จากแพ็กเกจนี้ โดยอ่าน yamaha-fg800j.json และใช้ภาพ images/yamaha-fg800j-natural.jpg ที่แนบมา

1. ตรวจสอบโครงสร้างข้อมูลสินค้าและ FG800J เดิมก่อน ห้ามสร้างซ้ำ ห้ามสับสนกับ FG800
2. วางภาพไว้ในตำแหน่ง assets จริงของโปรเจกต์ แล้วแก้ path ให้ถูกต้อง ตรวจสอบภาพแสดงใน Catalog และ Detail
3. เพิ่มคำอธิบายและสเปกภาษาไทยทั้งหมดตาม JSON
4. สำคัญ: priceTHB เป็น null เพราะยังไม่ยืนยันราคา FG800J ในไทย ตัวเลข 12,400 บาทเป็นราคาของ FG800 รุ่นปกติเท่านั้น ห้ามแสดงเป็นราคา FG800J ให้ใช้ข้อความ 'รอยืนยันราคา' หรือ UI ที่เหมาะสม ห้ามนำค่า null ไปทำให้ Compare/Filter พัง
5. รักษาจำนวนกีตาร์เดิมและฟีเจอร์ Compare, Wishlist, Find My Guitar, Search และดีไซน์ดำทอง
6. อย่า merge เข้า master โดยไม่ได้รับอนุญาต ตรวจสอบ npm run build และรายงานการเปลี่ยนแปลง
7. หากพบราคาขาย FG800J ในไทยจากแหล่งที่ตรวจสอบได้ภายหลัง ให้แจ้งผู้ใช้ก่อนอัปเดต
