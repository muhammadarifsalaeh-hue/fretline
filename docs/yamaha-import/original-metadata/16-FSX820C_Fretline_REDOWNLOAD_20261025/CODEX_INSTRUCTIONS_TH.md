# คำสั่ง Codex สำหรับ Fretline — Yamaha FSX820C

นำข้อมูลจาก `yamaha-fsx820c.json` และภาพ `images/yamaha-fsx820c-two-colors.jpg` ในแพ็กเกจนี้ เข้าเว็บไซต์ Fretline

1. สำรวจโครงสร้างโปรเจกต์และ schema ของสินค้าเดิมก่อนแก้ไข ห้ามแทนที่ฐานข้อมูลเดิมทั้งไฟล์โดยไม่จำเป็น
2. เพิ่มหรืออัปเดตรุ่น Yamaha FSX820C ด้วย id `yamaha-fsx820c` หากมีอยู่แล้วห้ามเพิ่มซ้ำ และห้ามแก้รุ่น FGX820C/FSX830C
3. คัดลอกภาพไปยังโฟลเดอร์ assets/public ที่ใช้งานจริง และแก้ path รูปให้ตรงกับโครงสร้างโปรเจกต์ (path ใน JSON เป็นเพียงตัวอย่าง)
4. ภาพมีสองสี Natural และ Brown Sunburst ในรูปเดียว: สร้างเป็นสินค้ารุ่นเดียว และอย่าแยกเป็นสองรุ่น
5. แสดงราคาอ้างอิง 20,500 บาท คำอธิบายภาษาไทย สเปกทั้งหมด และหมายเหตุราคาอาจเปลี่ยนแปลง
6. เชื่อมเข้ากับ Catalog, Search, Compare, Wishlist และ Find My Guitar เท่าที่โปรเจกต์มีอยู่แล้ว โดยไม่ทำให้ฟีเจอร์เดิมเสีย
7. คงธีมดำ-ทองและรองรับหน้าจอ iPad/mobile; อย่าลบหรือแก้ข้อมูลกีตาร์รุ่นอื่น
8. ตรวจสอบสเปกที่ต่างตามล็อตก่อนเผยแพร่; ห้ามเติมข้อมูลที่ไม่มีหลักฐาน
9. รัน build/tests ตาม scripts ใน package.json รายงานผลและไฟล์ที่แก้ไข
10. ห้าม merge เข้า master หรือ push โดยไม่ได้รับอนุญาต
