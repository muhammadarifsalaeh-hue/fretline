## Evidence notes

- Yamaha FGX04: file page identifies the Yamaha instrument, author and CC BY 2.0. Flickr license was reviewed by Leoboudv on 22 July 2015.
- Fender Jag-Stang: file page identifies a 1996 Fender Jag-Stang headstock, own work by Quentin Thiel, released under CC BY-SA 4.0.
- Gibson headstock: file description identifies a Gibson Les Paul; own work by Eric052492. Multiple licenses are offered; the table selects CC BY-SA 3.0.
- Taylor: file description identifies the Taylor guitar. Flickr license was checked on 31 March 2013. Current higher-resolution upload is from 21 October 2017.
- Ibanez: file caption identifies the ICX120, own work by Elmschrat, CC BY-SA 4.0. Original has EXIF rotation; apply orientation before optimization.
- PRS: file caption identifies the 2009 PRS McCarty Trem Quilt LTD; Flickr author Freebird. Commons Flickr review confirmed CC BY-SA 2.0 on 24 August 2024. Current original is landscape 3765×2493 (reverted from an intervening rotation).
- Epiphone: file description identifies the Les Paul Special II headstock, own work by Elmschrat, CC BY-SA 4.0.
- Martin: file caption identifies JC-16ME Aura; Flickr author Elías Gómez. License was confirmed on 14 July 2013.
- Squier: own-work caption explicitly identifies the Squier logo on an electric guitar headstock; author Tharish, CC BY-SA 3.0.

## Córdoba exclusion record

Two exact-brand candidates were opened and excluded because their pages state **All rights reserved**:

- [Signature Cordoba Fusion Headstock, Córdoba Guitars](https://www.flickr.com/photos/cordobaguitars/3877921735/)
- [Cordoba C5, Aperture Life Photography](https://www.flickr.com/photos/aperturelife/4267871471/)

Searches also found guitars photographed in the Spanish city Córdoba. Those are not evidence of the Córdoba guitar brand and must not be used as brand backgrounds.

## Implementation attribution

Record source URL, author, license URL, access date, local filename and transformations for each selected image. Credit should be accessible from the page. For derivatives, state cropping, color grading, resizing and WebP conversion as applicable and retain the indicated share-alike license on CC BY-SA image derivatives. A photographic license does not supply an official brand logo asset or imply brand endorsement.
