# Reference comparison — actual Homepage

The original user attachment (1280×853) was accessible locally and reviewed
alongside the actual 1280px application render. Its hash and the measured browser
geometry are in [visual-comparison.json](visual-comparison.json). The reference
was not copied into the website, sliced into brand photos, or used as a fake logo.

[Actual Explore by Brand at 1280px](after/brands-reference-desktop.png)

| Aspect | Actual result / comparison |
| --- | --- |
| Structure | Same ten brands and order, five equal columns × two rows on desktop |
| Grid placement | At 1280px: left edge 24px; first card starts 284.27px below section top, approximately the reference's 284px |
| Card geometry | 238.39 × 248.31px, 10px gap, 6px corners, restrained gold border |
| Title | Same two Thai lines, warm white then champagne; the approved local Anuphan font remains consistent with Phase B, so exact glyph width differs |
| Brand marks | Nine genuine distinctive marks rather than a repeated generic font; white transparent marks layered over real brand imagery |
| Squier | Source's genuine oval variant, not the reference's unframed script variant; original contrast preserved |
| Córdoba | Honest temporary sans name and neutral dark background; no fake logo or other-brand instrument |
| Backgrounds | Nine licensed photographs of the correct brands, framed and graded dark/warm; different from reference photos and studio lighting |
| Header image | Licensed Fender headstock, darkened and diagonally framed; a different headstock/photo than the reference |
| Card details | Real 20-model counts, short gold rule, lower-right round arrow; whole-card keyboard/touch links |
| Lighting/motion | Subtle warm hover feedback, no continuous marquee or image hover zoom; reduced-motion supported |
| Credits | Additional disclosure below the grid carries photo/source licenses and trademark notes, increasing section height to about 913px |
| Responsive | 5 columns at1440/1280,3 at1024,2 at768/390/320; no horizontal page overflow, contained marks and separated count/arrow |

The repeated geometry, hierarchy, black canvas, thin gold edges and placement
closely follow the reference. Photographic composition, mark variants, Thai
letterform widths and Córdoba remain visible differences. No pixel-perfect claim
or invented similarity percentage is made.
