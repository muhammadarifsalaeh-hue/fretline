- Acoustic: real steel-string Jeff Yong guitar photograph by **Fingerstylefreak11**, [source](https://commons.wikimedia.org/wiki/File:Guitar-jeffyong.png), **CC BY-SA 3.0**. Publisher supplied an original black backdrop. Two proportional WebP versions preserve it. The best source is 231×548, sufficient for the small category display; no fictional high-resolution claim or upscaling.
- Classical: reuses the already licensed Martin Möller / Mouh2jijel photograph, **CC BY-SA 2.0 DE**, with source alpha.
- Bass: reuses the already registered Patrick Scales / Djhé public-domain photograph, with source alpha.

All licensing metadata was fetched from Wikimedia Commons on 2026-10-27 and retained in `*-source-observation.json`. Original and derivative SHA-256 checksums, author, source URLs, and dimensions are recorded in `category-manifest.json`. No new AI-generated image, crop, recoloring, or synthesized product. WebP derivatives retain the original work's indicated license.

Attribution is visible on the site's existing `/image-credits#home-photography` page, reached through the global footer. The homepage itself needs no redundant photo caption.
