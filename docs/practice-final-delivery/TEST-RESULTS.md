## The initial preparation failure remains a failure

The first invocation's two trainer commands stopped **before starting browser
cases**: the test adapter searched for one button assertion, but the canonical
suite contains it both when opening and closing inspection. The preparation
assertion failed. Those logs and the initial false summary are retained in
[the initial report folder](tests/reports/final/).

The adapter was corrected to match the unique opening assertion followed by
canvas setup. A dry `--help` invocation exercised its transformation assertions.
No expected app behavior or runtime source was changed. The other initial
suites completed successfully, then only the two unstarted trainer suites were
rerun, serially, in [a fresh report folder](tests/reports/trainers-retest/).
Both actually completed 21/21. The [acceptance checker](tests/accept-results.py)
verifies expected counts, all ancillary passes, source hashes and identical
production bytes across both folders. The initial run is never relabelled pass.

The owned adapter retains the canonical 21-case plan and 800 ms idle assertion,
plus the previously measured startup-settlement wait. The former F inspection
case is intentionally **stronger**: a geometry-rejected F must have no inspector
control, a hidden hand, a correct diagram and a drawn fallback neck. C retains
actual pixel-change and four-view assertions. The original suite file remains
unchanged. These results are not called an unchanged historical invocation.

## Geometry and anatomy are separate

No new central candidate passed all physical criteria, even though 16 reached
zero self crossings. The selector rejected stale/incomplete/wrong-owner evidence
and preserved all seven audited runtime endpoints. The source model, rig/weights,
chords and saved runtime poses remain byte-identical to `96e0449`.

The original runtime full-mesh audit remains applicable through exact model and
transform hashes. This delivery does not pretend a repeated build newly verifies
all anatomy. No gate was loosened and no chord was edited to force a fit.
