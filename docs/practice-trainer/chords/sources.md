## Independent checks and limits

Fret arrays are checked against independently declared standard-tuning MIDI numbers 40,45,50,55,59,64. Absolute note pitches and exact pitch-class sets are calculated; spelling is allowed to be enharmonic. A quality formula cannot establish finger feasibility, so separate checks validate repeated fingers, barre endpoints, covered higher-fretted strings, open/muted clearance, and a bounded fret span. The independent audit uses its own fixtures/calculations.

Conventional seventh chords can omit their fifth. We select the documented open C7 to keep a familiar learner shape; all other selected records contain their full quality formula. [Guitar-chord.org Bmaj7](https://www.guitar-chord.org/bmaj7.html), also read, explicitly explains that its open x2130x omits fifth F#. Our Bmaj7 x24342 includes it.

Some source prose has mistakes (including Fender Bm string labels and occasional guitar-chord.org explanatory note lists); arrays are not copied blindly. A JustinGuitar Dsus2 fetch exposed only a title, so no page-content review or verification is claimed for it. External learning references are factual support, never hand-rig or rendered-diagram certification.
