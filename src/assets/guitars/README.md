# Guitar photos

One folder per model, named exactly like the guitar `id` in `src/data/guitars.js`:

```
src/assets/guitars/
  fender-player-ii-jazz-bass/
    01-front.webp        <- main photo (cards, compare, quiz, search)
    02-angle.webp
    03-headstock.webp
```

Only photos of that exact model. See `MISSING_IMAGES.md` for the full list and `npm run images:check` to see what is still missing.
